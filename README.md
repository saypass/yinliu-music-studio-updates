安装包不包含 DeepSeek、可爱云、Suno、明月浩空任何 API Key。新用户在“接口设置”填入自己的 Key，首次安装创作清单和素材目录为空。

旧用户直接覆盖安装，保留本地已保存的 Key、存储位置和作品，请勿先删除用户数据。v1.0.6 Windows 版启动后约 15 秒检查更新，发现新版后可点击“下载更新”，下载完成后重启安装。网络无法连接 GitHub 时可用上述链接手动下载。未签名 macOS 版建议下载 DMG 手动覆盖安装。

v1.0.7 为每个生成音乐版本提供独立、可折叠的歌词框，并显示参考原曲。
